# המסע לאנגלית 🌟📘

קורס אנגלית אינטראקטיבי בעברית מלאה (ממשק RTL), בנוי כאתר סטטי אחד שרץ בכל דפדפן — בלי התקנות, בלי שרת.

## מה יש בפנים

- **10 יחידות לימוד** מהיסודות (ברכות, מספרים, משפחה) ועד משפטים שימושיים ופעלים יומיומיים.
- **מגוון סוגי תרגילים** בכל שיעור: בחירה רב-ברירתית (עברית↔אנגלית), האזנה להגייה (Text-to-Speech), התאמת זוגות, והקלדת תשובה.
- **התקדמות נעולה בשלבים** — יחידה נפתחת רק אחרי סיום היחידה הקודמת, כך שיש מסלול ברור וללא בלבול.
- **לבבות (חיים)** בכל שיעור, כדי לשמור על מתח קליל ומוטיבציה.
- **מתנה בסוף כל שיעור** 🎁 — אנימציה, אמוג'י הפתעה, והודעת עידוד אישית בעברית.
- **עיטורים (Badges)** שנפתחים בציוני דרך (יחידה ראשונה, חצי מהדרך, סיום הקורס...).
- **רצף ימי למידה (Streak)** וכוכבים שנצברים, כדי לעודד הרגל יומי.
- **תעודת סיום** מותאמת אישית עם השם של הלומד/ת, בסיום כל 10 היחידות.
- **שמירת התקדמות** מקומית בדפדפן (localStorage) — אפשר לצאת ולחזור בכל זמן בלי לאבד כלום.

## איך מריצים

פשוט פותחים את `index.html` בדפדפן (או מגישים את התיקייה עם כל שרת סטטי, למשל `python3 -m http.server`).

## מבנה הקבצים

- `index.html` — מבנה כל המסכים באפליקציה.
- `style.css` — עיצוב מלא, כולל תמיכה במצב כהה.
- `lessons-data.js` — כל תוכן הלימוד: יחידות, אוצר מילים, הודעות עידוד, מתנות ועיטורים.
- `script.js` — מנוע האפליקציה: ניהול מסכים, בניית תרגילים, לוגיקת תרגול, שמירת התקדמות.

## הרחבה עתידית

כדי להוסיף יחידה חדשה, פשוט מוסיפים אובייקט חדש למערך `COURSE_UNITS` בקובץ `lessons-data.js` עם `id`, `icon`, `title`, `subtitle` ורשימת `vocab` — המנוע יבנה את התרגילים אוטומטית.
